JobCapturePro embed demo. Build first (npm run build), serve the repo root (python3 -m http.server 8734), then open /examples/embed-demo.html?apikey=KEY&companyid=ID. Optional params: component (combined | checkins | map | company-info | checkin) and any shortcode att (checkinid, pagesize, state, …) — all are forwarded as widget attributes.
